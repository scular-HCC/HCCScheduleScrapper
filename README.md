# HCC Schedule Scrapper
- This is a webscrapper that collects the course information from the active HCC schedules.
- User can choose the year, term, and subjects.
- The data is saved as a csv that can be then analyzed in the Web Schedule Analysis App



# Web Schedule Analysis
- This program takes either the webscrapped data or student enrollment report.
- User can select courses and have them put on a weekly calendar.
- Conflicts in time are highlighted and printed in the left side bar.
- To run this App you must start a webserver on your computer.
-- Run this command in the directory with the app: python -m http.server 8000
-- Use the app in a webbrowser by loading localhost:8000
